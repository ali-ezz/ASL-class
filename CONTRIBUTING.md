# Contributing

Thanks for taking the time to contribute to this ASL hand sign recognition project.

## How to contribute

- Open an issue for bugs, questions, or feature ideas.
- Create a branch for your work with a descriptive name such as `fix/streamlit-startup`, `feat/model-import`, or `docs/readme-update`.
- Submit a pull request with a clear summary of the change.

## Pull request expectations

- Include a short description of what changed and why.
- Reference the issue number if applicable.
- Add or update documentation when needed.
- Keep changes small and focused.
- Ensure the code is readable and follows the existing style.

## Branch naming

Use a consistent branch naming pattern such as:

- `fix/<short-description>`
- `feat/<short-description>`
- `docs/<short-description>`
- `chore/<short-description>`

## Review

Pull requests should be reviewed before merging. If a PR needs attention, mention the reviewer or assign the pull request to a maintainer.

## Code quality

- Keep code changes localized.
- Add comments only when they improve readability.
- Do not commit large generated files or model artifacts.
