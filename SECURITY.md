# Security Policy

If you discover a security issue in this repository, please report it responsibly.

## Reporting a vulnerability

1. Create a private issue if the repository supports it.
2. If private issues are unavailable, open an email to `security@ali-ezz.dev` with details.
3. Include:
   - a description of the issue
   - steps to reproduce
   - environment and dependency versions
   - proof of concept if available

## Response

A maintainer will acknowledge receipt as soon as possible and provide a plan for remediation.

## Supported versions

This repository uses Python 3.11 and dependencies listed in `requirements.txt`.

## Disclaimer

Do not post security vulnerabilities publicly until they have been addressed.
