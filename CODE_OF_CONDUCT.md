# Code of Conduct

This project follows a standard code of conduct to set expectations for contributors.

## Our standards

- Be respectful and professional.
- Assume good intent from other contributors.
- Be open to feedback and constructive discussion.
- Keep discussions and reviews focused on code, design, and user value.

## Unacceptable behavior

- Harassment, abuse, or discriminatory language.
- Personal attacks or harassment of any contributor.
- Posting threats, hateful content, or offensive material.
- Sharing private information without consent.

## Enforcement

If you observe inappropriate behavior, please report it to the repository maintainers.

## Attribution

This code of conduct is adapted from common open source contributor guidelines.
